# Internal storage

Supported on Snapdragon 8 Elite (AYN Odin 3), 8 Gen 3 (KONKR Pocket FIT, AYANEO Pocket S2), and 8 Gen 2 (AYN Odin 2 / Mini / Portal).

Once it runs from the SD card, open **Zaviya Installer** in Desktop Mode, pick how much space Android keeps, and choose whether your games come along. This erases Android's user data (Android itself stays and sets itself up again), and the old partition table is saved on the SD card so you can give the space back later.

When it's done, set **Boot source** to **Internal** in the ABL menu. If you installed an older version to internal before, run **UNINSTALL CFW** in the ABL menu first.

The installer also works in Game Mode now: it is a section in Zaviya Control.

More details in [external-and-mods/ufs-install](../external-and-mods/ufs-install/README.md).
